Native macOS · menu bar only

Your laptop's health, drawn as a line on the edge of your screen.

petze renders battery, CPU, memory, and network as thin color-coded lines that hug the edge of your display — and by default it shows only what matters right now. No Dock icon, no windows, no cloud. Just ~500 lines of Swift and AppKit.

Features

Glanceable. Silent. Native.

Three metrics, one pixel-thin strip. Each line's length is the level; its color is the verdict.

▁

Only what matters

Automatic mode shows a single memory line on a quiet machine. Battery appears when charging or running low, CPU when it crosses 60%, network when traffic flows — and each retracts when the moment passes.

⌘

Three positions

Top edge, bottom edge, or a frame that travels clockwise around the whole screen — a full battery draws a complete border.

✦

Buttery animations

Lines glide between values with Core Animation ease-in-out — no jumps, no flicker, just a calm strip that breathes with your machine.

🖱

Click-through overlay

The lines float above everything but swallow no clicks, appear on every display and every Space, and survive fullscreen apps.

♥

Honest system data

IOKit power sources for battery, mach host statistics for CPU and memory, interface counters for network — the same numbers top, pmset, and nettop report.

◎

Nothing else

No Dock icon, no login nag, no analytics, no phoning home. Quit it from the menu bar and it's gone.

Color language

The color is the diagnosis.

You never read a number unless you want to — the hue tells you whether to care.

Battery line

Charging
On AC, full or holding
Discharging
Discharging, ≤ 20%

CPU & memory lines

Below 60% — all quiet
60–85% — working hard
Above 85% — under pressure

Network lines

Inbound — log scale, 10 KB/s → 100 MB/s
Outbound — same scale
Quick start

Build from source.

Requires macOS 13+ and Xcode command line tools. No dependencies.

$ git clone https://github.com/alileza/petze.git
$ cd petze
$ ./make-app.sh          # builds release binary + petze.app
$ open petze.app         # lines appear; configure via the ⚡ menu bar icon

# optional: start at login
# System Settings → General → Login Items → add petze.app
